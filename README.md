# Puja Mohapatra — Website V23

Based on the V22 website with a rebuilt Customize Center.

- Content editor: site, hero, biography, services, journey, approach and contact.
- Image editor: Hero, About, Services, Journey, Practice, Approach, Reviews, FAQ, Contact and CTA.
- Design editor: colors, fonts, radius and motion setting.
- One V23 localStorage configuration key and one V23 IndexedDB image store.
- Android-friendly image selection.
- Reset controls.

Important: Customize Center changes are stored locally in the browser/device. They do not upload edited images to GitHub automatically.
