# Puja Mohapatra Clinical Psychology — V11.4

Premium responsive clinical psychology website with editorial visual hierarchy, mobile navigation, section-by-section motion, responsive layouts, and a browser-based customization layer.

## Structure
- `index.html` — main website
- `customize.html` — browser-local editor
- `config.js` — editable content/configuration
- `css/style.css` — responsive design and animation system
- `js/script.js` — rendering, navigation, reveal motion and interactions
- `assets/` — logo and hero imagery

## Customization
Update verified professional information, services, qualifications, contact details, images, colors and other content in `config.js`. The editor provides a local preview; permanent published changes require updating `config.js` in GitHub.

## Motion
Animations include hero sequencing, scroll reveals, card interactions, navigation transitions and marquee motion. `prefers-reduced-motion` is respected.

## Publishing
Deploy the repository root through GitHub Pages using the `main` branch.
