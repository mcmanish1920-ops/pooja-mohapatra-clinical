# Pooja Mohapatra Clinical Psychology — V10

GitHub Pages-ready static website. Upload the contents of this folder to the repository root.

## Structure
- `index.html`
- `customize.html`
- `config.js`
- `css/style.css`
- `js/script.js`
- `assets/hero.jpg`
- `assets/logo.png`

## Customization
`customize.html` saves browser-local customization to localStorage for preview. For permanent published values, update `config.js`.

## GitHub Pages
Use branch `main` and folder `/ (root)`.
