# Puja Mohapatra Clinical Psychology — V11

A premium, responsive clinical psychology website designed with a calm, elegant editorial aesthetic.

## Included

- `index.html` — Main website
- `customize.html` — Browser-based customization panel
- `config.js` — Central configuration for name, contact details, credentials, services, FAQs, and other editable content
- `css/style.css` — Responsive premium styling
- `js/script.js` — Interactive behavior, animations, mobile navigation, and dynamic content rendering
- `assets/hero.jpg` — Hero/practice image
- `assets/logo.png` — Website logo

## Design

- Cream and deep-green visual palette
- Elegant clinical/editorial layout
- Responsive mobile and desktop design
- Smooth scrolling
- Scroll reveal animations
- Accessible reduced-motion support
- Mobile navigation
- Service, journey, approach, FAQ, reviews, and contact sections

## Customization

Open `config.js` and replace the placeholder information with verified professional details before publishing.

You can also use `customize.html` to preview supported content changes in your browser.

## Important

Keep professional credentials, registration information, experience, contact details, and testimonials accurate and verifiable. Do not publish placeholder information as factual credentials or client reviews.
