WEBSITE EDITOR · V21.0

Customize the practice site.

Change your content, colors, and every section image from one place. The editor works directly in this browser and updates the website preview immediately when you return to the site. Images are saved in this browser using IndexedDB, so the image picker works reliably on Android and does not depend on localStorage size.

Section images

Each titled section has its own image slot. Tap Choose image, select a photo from your phone, and the preview updates immediately; the same image is applied to that section on the website.

View Website

Important: Customize changes are a browser preview. They appear on the website when that website is opened in the same browser/device. To make a change permanent for everyone, publish the chosen image inside assets/ and set its path in config.js.
